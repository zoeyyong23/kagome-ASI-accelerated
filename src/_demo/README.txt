Description of each File:

- File Name: generate_demo_seed_data.py
	- Overall Description:
		Writes a synthetic single-device seed CSV pair (m_full + B_demag)
		for demo_superposition.py, so it runs standalone without a real
		mumax3 simulation on hand. Builds an anti-aliased elliptical device
		footprint for m_full, and its real dipole-summed B_demag stray field
		via magnetostatics.Magnetostatics.
	- Functions:
		- generate_demo_seed_data(data_directory, sim_size_cells,
		  device_size_cells, cell_size_x=1.0, cell_size_y=1.0,
		  device_angle_deg=0.0, Ms=800e3, thickness_nm=2.5,
		  magnetostatics_resolution=8, frame_index=0, verbose=False)
			- Function Description: builds the seed device and writes both
			  CSVs, in mumax3's real blank-line-separated stacked format.
			- Returns: {"m_full": path, "B_demag": path}.

- File Name: generate_parallelization_test_files.py
	- Overall Description:
		Produces a handful of standalone m_full/B_demag CSV files -- one per
		randomized "regeneration" across the same small ASI array -- for
		testing parallelization against real multi-frame data, and as
		demo_spatial.py's own input data.
	- Functions:
		- main(num_regenerations=6, verbose=True)
			- Function Description: generates a seed device if needed, runs
			  mumax3_parent_superposition.run_pipeline with magnetization_
			  mode="random" and every downstream plotting/stats step
			  disabled, then converts each composed-canvas frame to a
			  standalone CSV.
			- Returns: List[str] of every CSV path written.

- File Name: plot_single_field.py
	- Overall Description:
		Standalone script: load and plot ONE mumax3-style field file, with
		no dependency on the rest of this package -- just this file, numpy,
		and matplotlib. A quick, hackable entry point for one-off
		exploration, runnable from the command line or imported as a
		library.
	- Functions:
		- load_field(path, verbose=False)
			- Function Description: loads x, y, z from a CSV or .npz field
			  file.
		- run_custom_analysis(x, y, z, cell_size_x=1.0, cell_size_y=1.0,
		  verbose=False)
			- Function Description: a documented no-op stub, called right
			  after loading -- the intended place to add ad hoc analysis.
		- plot_single_field(x, y, z, plot_type="magnitude", ...,
		  verbose=False)
			- Function Description: renders one plot -- magnitude, angle, a
			  raw component, or an averaged quiver.

- File Name: magnetostatics.py
	- Overall Description:
		Analytic point-dipole model for the magnetostatic (stray) field
		generated by an array of elliptical magnetic elements. A standalone
		physics utility with no dependency on the rest of this package's
		pipeline -- operates purely on plain center/angle arrays.
		generate_demo_seed_data.py uses this class directly to produce a
		physically realistic B_demag test field.
	- Functions:
		- Magnetostatics.__init__(centers, angles_deg, Ms=800e3,
		  device_length=60e-9, device_width=60e-9, thickness=2.5e-9,
		  resolution=5, verbose=False)
			- Function Description: precomputes every device's sub-dipole
			  grid (positions and moments). NOTE: centers is in nm; device_
			  length/device_width/thickness are in meters -- easy to mix up.
		- compute_field_at_points(points, verbose=False)
			- Function Description: the core calculation -- sums every
			  sub-dipole's analytic field contribution at a set of query
			  points. This is a point-dipole-sum approximation; it diverges
			  near its own source points (expected of this model, not a
			  bug).
		- compute_field_over_device_volume(position, angle_deg,
		  probe_points=None, verbose=False)
			- Function Description: averages the field over a device-shaped
			  probe volume -- typically used to evaluate the field acting ON
			  one device due to every OTHER device.
		- compute_local_fields_for_all_devices(device_array_obj, ...,
		  verbose=False)
			- Function Description: local field at every device in a
			  geometry.DeviceArray, excluding each device's own contribution.
			  Not currently called anywhere in this package. Fixed in this
			  revision: a column-order swap, a call to a function that only
			  existed inside this file's own __main__ block, and a dict-
			  unpacking crash -- see the source's own module-level
			  LIMITATIONS section for the full explanation of all three.


File Crossover:
	- generate_parallelization_test_files.py calls generate_demo_seed_data.py
	  for its seed device, then mumax3_parent_superposition.run_pipeline (at
	  the root of this package) to actually compose the canvas.
	- generate_demo_seed_data.py calls magnetostatics.Magnetostatics
	  directly for its B_demag field.
	- demo_spatial.py and demo_superposition.py (at the root of this package)
	  are the only callers of this folder's functions -- nothing in
	  src/_mumax3 or src/_superposition imports from src/_demo. This
	  directory can be removed entirely without affecting the rest of the
	  package; it exists purely to make the package runnable standalone for
	  testing/demonstration.
